# 👾 UFO Attack

**UFO Attack** is a simple game developed in C# using Windows Forms. The player must destroy enemy UFOs descending on the screen. This project was created to practice programming logic, UI development, and basic game mechanics within a desktop application.

## 🛠️ Technologies Used

- C#
- .NET Framework
- Windows Forms (WinForms)

## 🚀 How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/maridsfa/UFO-Attack.git

2. Open the solution file trab_prog.sln using Visual Studio.

3. Build and run the project (F5).

## 🎮 How to Play

- Control your spaceship to shoot down incoming UFOs.

- Your goal is to destroy as many enemy ships as possible before they reach the bottom of the screen.

- Use the arrow keys to move and the spacebar to shoot.

## 📁 Project Structure

- Form1.cs: Main game logic.

- Program.cs: Entry point of the application.

- Form1.Designer.cs: Automatically generated file containing the form's layout.

- .resx: Resources used in the form design.

- .sln and .csproj: Visual Studio solution and project files.
